# سامانه استعلام قیمت برلیانس H320 اتوماتیک موتور ۱.۶۵

سامانه هوشمند و داشبورد تحلیلی آنلاین جهت استعلام، مقایسه و برآورد قیمت خودرو **برلیانس H320 اتوماتیک موتور 1.65** از سه منبع معتبر بازار خودرو ایران:
1. **دیوار (Divar)**: استعلام آگهی‌های فعال بازار به همراه کارکرد، موقعیت جغرافیایی و قیمت‌های اعلامی
2. **همراه مکانیک (Hamrah Mechanic)**: نرخ‌های کارشناسی رسمی و بازه منصفانه قیمت برای سال‌های ۱۳۹۷ تا ۱۴۰۰
3. **باما (Bama)**: آخرین آگهی‌های تریم ۱.۶۵ اتوماتیک

---

## قابلیت‌های برجسته

- **پایش زنده و هوشمند (Live Monitoring)**: استخراج همزمان قیمت‌ها با روت‌های Serverless Next.js.
- **معماری دو لایه و مقاوم (Smart Fallback)**: تضمین عملکرد همیشگی روی سرورهای خارجی Vercel بدون نگرانی از اختلالات اینترنت بین‌الملل.
- **ماشین‌حساب هوشمند تخمین قیمت (Valuation Tool)**: محاسبه دقیق ارزش منصفانه خودرو بر اساس سال ساخت، کارکرد دقیق به کیلومتر، وضعیت رنگ و بدنه و سلامت گیربکس اتومات.
- **جدول مقایسه‌ای سال به سال**: مقایسه کف، میانگین و سقف قیمت بازار با نرخ کارشناسی رسمی همراه مکانیک.
- **طراحی مدرن و کاملاً واکنش‌گرا (RTL + Tailwind CSS)**: پشتیبانی کامل از زبان فارسی و نمایش بهینه روی موبایل، تبلت و دسکتاپ.

## نحوه اجرای محلی (Local Run)

۱. نصب وابستگی‌ها:
```bash
npm install
```

۲. اجرای سرور توسعه:
```bash
npm run dev
```
سپس مرورگر خود را باز کرده و به آدرس [http://localhost:3000](http://localhost:3000) بروید.

۳. بیلد نهایی پروژه:
```bash
npm run build
```

## نحوه پوش (Push) به گیت‌هاب (GitHub)

در پوشه پروژه، مراحل زیر را در ترمینال اجرا کنید:

```bash
# مقداردهی و افزودن فایل‌ها
git init
git add .
git commit -m "feat: initial commit for Brilliance H320 price tracker"

# اتصال به مخزن گیت‌هاب شما (مثال)
git branch -M main
git remote add origin https://github.com/faramarz06/bereliance-price.git
git push -u origin main
```

## استقرار روی ورسل (Deploy to Vercel)

۱. وارد حساب کاربری خود در [Vercel](https://vercel.com) شوید.
۲. روی دکمه **Add New Project** کلیک کنید.
۳. ریپازیتوری گیت‌هاب خود (`bereliance-price`) را انتخاب و دکمه **Import** را بزنید.
۴. بدون نیاز به تغییر تنظیمات، دکمه **Deploy** را بزنید! وب‌سایت شما ظرف چند ثانیه آنلاین خواهد شد.
